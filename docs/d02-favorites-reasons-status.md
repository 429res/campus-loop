# D-02 收藏夹与推荐理由展示

更新日期：2026-09-08。本切片接入已合入 main 的 B-02 独立需求推荐与 A-02 收藏接口；收藏状态和分页均从服务端读取，不使用本地缓存伪造持久化。

## 实际接入

- 推荐页调用登录接口 `GET /api/matches/independent?ruleVersion=independent-v2`，不回退或混入公开 `legacy-v1` 结果。
- 页面直接展示服务端返回的双方/三方参与者、提供者→接收者物品流向、`demandId`、其他命中需求数量、命中分类、命中标签、reason、explanation 与规则版本；不在前端重算得分或选择需求。
- 分类明确标为硬条件，标签明确标为排序依据；requiredTags 和最低成色不显示为已启用规则。
- 刷新会取消旧请求并以 generation 防止旧响应覆盖。401 要求重新登录；422 单独解释为整次结果超限，不显示成空推荐；空数组单独显示真实空态。
- 页面只执行 GET；交换按钮禁用并标记留到 D-03，推荐浏览和刷新不创建交换、占用或其他业务状态。
- 发现卡片、详情和收藏夹调用 `PUT/DELETE /api/items/{id}/favorite` 及 `GET /api/favorites`。逐物品 busy 状态阻止连点；明确失败不改 UI，超时或响应丢失只回读收藏列表，不自动重放写请求。
- 收藏夹按服务端 `total/page/size` 分页；`itemVisible=false,item=null` 只展示物品 ID、收藏时间和取消入口，不显示缓存内容或打开详情。公开的 RESERVED/EXCHANGED 状态照服务端显示，但不宣称可交换或已占用。
- 收藏索引在账号变化时失效，加载和写入结果都校验当前令牌，旧账号响应不能覆盖当前页面。
