# 账号、社区与发布升级

## 实现范围

基于 `feature/member-trading`；保留已有交换事务、审核、通知和双端框架。新增迁移 V20/V21，不改写 V1–V19。

- 账号增加 email、emailVerified、legacyExchangeAccess、coverUrl、mailNotifications。历史账号保留交换/社区资格；新注册必须凭已验证邮箱完成注册。服务端再次校验互动资格。
- 注册前验证码、绑定邮箱验证码、用户名/邮箱登录；连续两次密码失败后使用本站图片 CAPTCHA。验证码单次消费、过期与频控，邮件令牌不进入日志。
- SMTP 通知投递采用持久队列，失败可重试，不回滚交换；新地址登录、密码修改/管理员重置等安全邮件由用户设置控制，日常业务仅站内通知。供应商未配置时明确不可用。
- 注销/管理员删除账号：检查未结束交换，撤销会话、匿名化个人资料、下架在架物品与需求、隐藏社区内容；保留交换和治理审计关系。
- 物品增加 imageUrls（最多 9 张，imageUrl 保持封面兼容）；图片上传上限 10 MiB，保留解码/像素限制。公开卡片等高容器内完整显示照片。
- 物品曝光配置为独立运营数据，管理员选择与排序；公开轮播仅展示当前可交换、作者有效的物品。
- 社区 PATCH 编辑须作者身份及 version；保持审核隐藏状态，编辑不绕过治理。发帖、回复、举报使用弹层，图片完整呈现并支持查看原图。
- 千问发布助手及管理员审核助手：服务端调用，提交前展示可编辑草稿；审核展示建议与理由，由管理员确认。限定任务上下文、调用频率和输出结构，不能由模型直接执行状态变更。
- 新增页头头像、主页背景、主题配色与风格选择；沿用浅/深色、减少动态效果与微信平台适配。
- Passkey 属于可选增强，本次未实现；当前认证为密码、邮箱验证码与按需 CAPTCHA。

## 外部配置

SMTP 和百炼均从服务端环境注入，禁止发送到浏览器或提交到 Git。配置字段见根目录 `.env.example`。生产设置 `CAMPUS_REGISTRATION_MODE=EMAIL_VERIFIED`，开发自助模式仅用于隔离环境。

邮件配置 SMTP_HOST/SMTP_PORT/SMTP_SSL/SMTP_USERNAME/SMTP_PASSWORD/MAIL_FROM；465 使用隐式 TLS，其余端口强制 STARTTLS。阿里云邮件推送需先验证发信域名、配置 DNS 并建立发信地址与 SMTP 密码。

百炼使用 DASHSCOPE_API_KEY/QWEN_BASE_URL/QWEN_MODEL，当前默认北京地域兼容接口及 qwen-plus。API Key 必须与地域一致，参见[官方开通说明](https://help.aliyun.com/zh/model-studio/get-api-key)。密钥仅保存于本地私密环境文件及服务器环境，不进入前端产物、Git 或发布包。

安全邮件默认由用户主动开启；邮箱注册和绑定验证码不受该开关影响。业务通知始终只在站内。新地址提醒基于服务端解析的成功登录来源地址变化，不能据此断定账号被盗；首次登录建立基线。

社区弹层和图片展示参考[Misskey 的帖子交互](https://misskey-hub.net/en/docs/for-users/features/note/)，保留 Campus Loop 的组件与视觉。
