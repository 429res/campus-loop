# 同学试用反馈修复 · 2026-09-09

本次基于已部署版本延续开发，修复八项交互反馈、交换发起报错，并丰富校园页面。

## 行为变化

- 账号管理操作列改为明确的按钮边界与可换行布局，五种操作保持可辨识。
- 页面返回统一走平台导航适配，直接进入详情时提供应用内兜底；移除重复返回入口。物品详情可选择本人符合双方需求的物品并发出交换邀请。
- 页面进入增加短过渡，主要列表和表单初次读取展示骨架；保留失败重试、禁用及减少动态效果。
- 个人中心常用入口放在资料表单上方并配图标，表单占满可用宽度，桌面两列、手机单列。
- 动态关联物品改为可搜索的图片卡片抽屉；匹配与动态使用更大的双入口，动态分页明确显示页数与总量。
- 自动需求随来源物品下架转为停用，重新提交审核时恢复；用户端同时提示来源物品的审核、交换中、已交换等状态。
- 动态信息流最多展示两条可见评论，详情可指定评论回复，并通知被回复者；撤回或停用账号的内容不泄露。
- 首页标语改为“用你的闲置，换到需要的好物。”，说明双方交换及三方循环的实际操作。
- 修复 UniApp 生产构建传递整个 `uni` 对象后存储/导航方法不可用的问题；所有交换持久请求使用显式平台适配器，保留幂等及未知结果恢复。
- 参考内容社区的横幅、分类与卡片层次，加入原创校园交换站插画、真实分类入口、交换示意及动态话题侧栏。

## 契约与迁移

新增 Flyway V19：评论可选父评论与索引，以及已下架物品对应自动需求的状态修复。旧迁移不改写；新增字段向后兼容。回复接口新增 `parentReplyId`，列表新增 `previewReplies`，详见 API 契约。直接交换复用独立需求推荐及现有创建接口，仍要求双方需求匹配、物品可用和事务内占用检查。
