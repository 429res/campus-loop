# 前端布局与图标修复

2026-09-09，对照 ProjectStudy-self 的公共材质与布局实现，调整 Campus Loop 管理端、H5 和微信共用组件。保留校园粉/蓝品牌、既有接口与业务状态。

## 修复内容

- 管理端侧栏的品牌与页脚固定在各自区域，菜单独立滚动；长菜单不再挤压底部说明。手机可滚动到最后一项。
- 登录和概览插画采用正常网格排布，移除旋转叠卡、覆盖文字的箭头和浮签。手机首页保留内容与主要行动，插画不覆盖正文。
- 按钮文字与图标使用明确间距，图标不压缩；标题、筛选和标签允许换行。手机表格取消左右固定列，由表格内部横向滚动，操作列不遮挡数据。
- 用户端 `LoopIcon` 使用统一 24×24 几何图标，替换导航、主题、搜索、收藏、关闭、个人中心与上传等入口的文字符号。图标框与按钮触摸区域分开计算，按钮保持 44px 点击区域。
- 个人中心入口使用图标、说明、箭头三列布局，说明和图标不共用绝对定位区域。
- 修复 UniApp H5 `uni-form` 内置 `span` 阻断 flex 间距的问题。登录、注册、资料、发布、需求及编辑等表单的字段间距恢复。
- H5 主导航由页面显式传入 `active-tab`，不依赖生命周期中尚未更新的页面栈；切换页面不会导致导航消失。底部为浮动导航和安全区域预留滚动空间。
- 弹窗、抽屉保留单层外壳、稳定正文、键盘焦点、Escape、反向开关、减少动态效果与实色降级。

## 资源维护

`shared/ui-icons.svg` 是图标源文件，横向 16 个图标、纵向 5 个色调，每格 24×24。按 3 倍尺寸、透明背景导出为 `wx-project-self/src/static/ui-icons.png`（1152×360）。图标顺序与 `LoopIcon.vue` 的 `names` 一致；色调依次为浅色次文字、深色次文字、浅色主色、白色、深色主色，值来自 `shared/design-tokens.css`。

H5 和微信均通过同一张 PNG 图集裁切显示，无图标字体、外部资源或新增运行依赖。新增图标需要同步源文件、PNG、名称表与图集尺寸。纯装饰图标隐藏于辅助技术，语义名称由按钮提供。
