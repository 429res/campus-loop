# 当前实现与验收范围

2026-09-09 平台补全分支：在已上线版本上补齐站内流程。具体接口见 [API 契约](api-contract.md)，本次验证与发布状态见 [平台交付](platform-completion.md)。

| 模块 | 当前实现 |
| --- | --- |
| 账号 | JWT 数据库会话、退出/改密撤销、头像、显示名称、简介、校区、私有联系方式、管理员启停与分模块授权；支持配置自助注册 |
| 分类与审核 | 分类新增/改名/启停/删除、版本与引用保护；物品审核及理由/审计 |
| 物品 | 发布、本人分页/详情、编辑后复审、AVAILABLE 下架、收藏；HIDDEN 编辑或重新上架后送审 |
| 独立需求 | CRUD、状态/版本冲突、关联本人可提供物品 |
| 匹配 | 有向双方/三方环，分类硬条件、标签排序，200件候选与结果限额，只读不占用 |
| 正式交换 | 事务重校验、唯一占用、幂等、逐人确认、取消、数据库UTC超时恢复 |
| 交接 | 逐人交出/收到声明，全部完成后原子转移所有权、关闭精确需求、追加履历和释放占用 |
| 争议 | 参与者登记后 DISPUTED 停止推进；管理员按同一事务恢复交接或在核实归还后终止交换，保留交接与裁决记录 |
| 履历 | 自述、修正链、私有图片、参与者独立确认/撤回、管理员单事件范围核验 |
| 通用举报 | ITEM 举报提交/幂等、本人回读、管理员受理/决定/审计及私有证据；处理不自动修改物品或交换 |
| 通知与运营 | 本人消息、未读/已读；审核、交换、举报、核验与权限变更通知；实时数量、日趋势、分类分布与操作审计 |
| 部署 | Linux Compose 全栈镜像、默认关闭注册/演示数据、HTTPS入口、健康检查、数据库/文件持久卷及备份 |
| 微信 | 构建与产物检查可执行，工具/真机、账号和合法域名仍需拥有者验证 |

## 尚未提供的产品能力

真实校园身份准入、微信授权登录、短信/邮件或外部通知、阿里云自动审核、OSS、大规模/多实例匹配与共享限流。不得把这些能力描述为已可用，也不能通过直接改表绕过已有状态机。
