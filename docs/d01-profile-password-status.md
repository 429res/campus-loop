# D-01 本人资料与修改密码切片

更新日期：2026-09-08。本切片消费 A-01 已实现的认证接口，只包含显示名称与修改密码；注册、联系方式、头像上传和角色编辑仍属后续范围。

## 接入行为

- `GET /api/auth/me` 是本人公开资料的读取与刷新来源。
- `PATCH /api/auth/me` 只发送 `{displayName}`；成功后使用完整响应替换本地公开用户缓存，不在客户端合并身份字段。
- `POST /api/auth/password` 只发送 `{currentPassword,newPassword}`；客户端校验旧密码必填且不超过 72 字符，新密码 12–64 字符且 UTF-8 不超过 72 字节，并要求二次输入一致。
- 改密成功后立即清除本机令牌与用户缓存，跳转登录页并提示使用新密码。密码字段不写入本地存储、日志或截图。
- 旧密码错误使用服务端 400 文案并允许修正。写请求超时或网络中断被标记为结果不确定：资料更新必须先重新查询；改密则清除本机会话并通过重新登录判断当前密码，不直接重放。

## 范围边界

客户端不复制密码哈希、会话撤销或并发锁逻辑。A-01 已在服务端事务与测试中覆盖双会话撤销及登录/改密并发；D 仅验证公开契约和用户恢复路径。其他设备在下一次受保护请求收到 401 后，由 `common/http.js` 清除旧会话并提示重新登录。
