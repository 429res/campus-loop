# 站内功能补全交付

基于已上线的品牌、注册与交换版本补齐截图中的六个模块；保留现有定向二/三人交换、履历证据和人工审核语义。

## 本次实现

- 个人资料：头像、名称、简介、学校/校区、私有联系方式，版本冲突恢复；账号管理增加 ALL 超级管理员与七类模块权限、会话撤销及权限变更审计。
- 交换与争议：保留邀请、确认、取消、到期和本人交接；争议可恢复交接或在核实归还后终止，锁与占用沿用原事务。重复决定不重写通知或履历，不代办收发。
- 物品履历：保留自述、维修/修正、私有证据、双方确认/撤回与管理员核验；核验结果通知作者，参与者可查看争议处理记录。
- 审核与举报：保留人工审核/退回和举报受理/处理；结果自动进入本人站内消息。
- 用户体验：收藏和独立需求保留，新增消息列表/未读/全部已读与对应业务跳转，HIDDEN 物品可编辑或重新送审上架。
- 运营：旧“后续业务”页替换为真实数据库汇总、7/30/90 天趋势、分类分布、物品/账号/举报/交换审计；导航按管理权限展示。

## 数据与接口

新增 Flyway V16：本人资料字段、权限字段、权限审计、通知、争议裁决记录及两个交换事件。既有管理员获得 ALL，普通用户不因此增加权限。保留旧数据、会话和业务记录，不改写已执行的 V1–V15。详细路径及字段见 [API 契约](api-contract.md)。

阿里云自动审核和 OSS 已按用户要求暂停，付费服务不启用；仍使用人工审核和现有文件存储。微信登录、真实校园身份核验、短信/邮件、多实例匹配与共享限流不在本次范围。
