# 四人后续开发与认领清单

本文件用于分工和排期；项目长期约定以根 [AGENTS.md](../AGENTS.md) 为入口，功能状态以 [roadmap.md](roadmap.md) 和实际源码为准。以下为模块目标，除下文单独标明的切片进度外，仍为**待认领、未完成**，A/B/C/D 是职责代号，成员姓名和 GitHub 用户名由团队填写。任务 ID 保持稳定，可直接用于后续 Issue 标题和 PR 关联。

## 已有基础与本轮目标

当前已实现登录/退出及数据库会话、默认关闭且仅供开发联调的自助注册、物品发布/图片上传/列表/详情、管理员只读记录与统计、双方/三方循环推荐、独立环境与迁移、两端控件展示。旧演示物品需求附在每件物品上；B-01 独立需求与候选关联、B-02 独立匹配、A-02 本人物品管理及收藏持久化后端已合入 main，收藏契约见 [收藏接入说明](a02-favorites.md)。D-02 需求管理用户端已合入 main，推荐理由和收藏页面在 PR #22 接入真实接口；本人物品管理仍待接入。公开或校园身份注册与履历审核仍未实现；当前分支交换创建/确认/取消进展见阶段2，不表示完整交换闭环。

`POST /exchanges` 已通过A-03接入B-03唯一创建事务；确认、取消、交接与争议登记均已接通共同事务，裁决仍未实现。概念表、页面入口、接口草案和演示数据均不代表业务闭环已经完成。下文提到的新增接口必须先更新 [api-contract.md](api-contract.md)，确认后再实现；不要据此直接调用不存在的接口。
