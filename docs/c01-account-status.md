# C-01 账号查询与启停管理端接入说明

状态：管理端已接入 A-01 的真实账号查询、状态更新与启停审计接口；本切片不扩展后端权限或账号状态机，也不代表整个 C-01 完成。

## 已使用契约

- 列表调用 `GET /api/admin/users`，使用服务端分页及 `keyword/role/status` 筛选，只展示 `id,username,displayName,role,status,version,createdAt`。
- 启停调用 `PATCH /api/admin/users/{id}/status`，仅提交 `{status,version,reason}`；理由 trim 后为1–500字符。
- 详情由当前列表安全字段和 `GET /api/admin/users/{id}/status-audits` 组成。审计仅展示契约允许的处理人、状态、理由、版本和UTC时间。
- 页面不请求、不缓存、不展示密码哈希、JWT、会话标识或认证头；权限仍由服务端 ADMIN 校验。

## 恢复与并发

- 提交期间禁止重复操作。成功后保留当前筛选和分页，从列表及审计 API 回读服务端状态。
- 409 保留理由和确认弹层，回读当前页及目标记录后要求管理员重新判断；不自动重试、不覆盖他人更新。
- 403 保留当前页面和输入；401 沿用统一请求拦截器清除会话并跳转登录。
- 自身账号、最后一个可用管理员、目标状态幂等、停用会话撤销及恢复启用不复活旧会话，全部沿用 A-01 服务端规则，前端只说明影响。

## 范围说明

本页不提供角色修改、密码查看/重置、账号删除或会话查看。停用不会由前端删除既有物品；推荐候选是否排除停用账号继续由后端 B-02 查询规则保证。
