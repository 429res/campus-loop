# C-03 管理交换查看

本功能基于已验证的阶段二修复 `e3d90e6`，与 D-03 正式交换操作在同一功能分支交付。管理端新增“交换记录”入口，读取真实分页、状态、参与者与流向、创建时摘要和持久审计，不提供代确认、代取消、代交接或争议裁决。

## 接口与隐私

`GET /api/admin/exchanges` 与 `GET /api/admin/exchanges/{id}` 独立要求 ADMIN。列表沿用六种交换状态及标准分页；详情返回 `{exchange,events,creation}`，精确字段及错误见 [API 契约](api-contract.md#c-03-管理交换读取契约)。管理员返回的 `allowedActions` 固定为空，原参与者接口的非参与者 404 边界保持。

管理读取与参与者读取复用同一个交换装配器和只读 REPEATABLE_READ 快照。参与关系来自已存交换，不能用流转后的当前 owner 重建历史。审计使用持久事件的状态、版本、时间和原因；显示名标明为当前名称，不伪造历史名称。创建摘要仅提取原创建快照中的物品标题、流向、命中需求编号和分类理由，不返回内部摘要、幂等键、原始 JSON、私人需求说明或技术重试字段。

旧记录没有创建快照时返回 null、没有事件时返回空数组，由页面明确说明。非法或不完整快照返回 409，不拼造历史。读取不锁业务行，不触发自动到期，不写业务或审计，无新迁移。

## 页面与失败恢复

“交换记录”支持按状态筛选、分页和详情抽屉。详情按参与者、提供者到接收者的物品流向、创建摘要及事件时间线呈现；仅后台允许的读取入口可见。空数据、加载中、网络失败、权限失效与记录完整性错误分别显示，失败可重新读取。

快速切换筛选/记录、关闭抽屉及换账号后，旧响应不得覆盖当前页面。管理员只读不会产生交换写请求。控件沿用现有 Element Plus、滚动锁与共享材质，覆盖清单见 [管理端控件规范](../project-self/docs/liquid-glass-controls.md)。
