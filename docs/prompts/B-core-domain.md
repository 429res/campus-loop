# B · 需求匹配、交换与履历开发提示词

B 主责独立需求、匹配规则、交换领域状态、履历可信度与领域测试；A 主责交换并发占用和超时基础，C/D 消费接口。任务来源为[四人工作计划](../team-work-plan.md)，长期规则以根 [AGENTS.md](../../AGENTS.md) 为准。

本文件是**待执行的开发计划**，不代表这些模块已经实现。一次只复制一个 `text` 代码块，在仓库根目录交给 Codex；先核对依赖的实际合入状态。每块可以独立使用，不必拼接公共前缀。完成一个切片后再认领下一块，不一次执行全部任务。

推荐顺序：B-01 → B-02 → B-03.1（与 A-03 协作）→ B-03.2 → B-04（与 A-04 协作）→ B-05.1 / B-05.2 → B-05.3。B-06 在正确性稳定且取得实际规模证据后进行。
