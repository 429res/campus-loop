# D：UniApp 用户端开发提示词

本文件对应 [四人任务计划](../team-work-plan.md) 的 D-01～D-04，共 9 个可独立交付的切片。下文小节编号仅用于拆分，不替代原任务 ID。共享规则始终以根 [AGENTS.md](../../AGENTS.md) 为准，本文件是任务提示词，不是另一套 Agent 规则。

每次在仓库根目录开启 Codex 任务，复制**一个完整的 `text` 代码块**。先核实依赖是否已合入、接口是否真实可用，再推进本切片；不要一次执行全部提示词。此处描述的是后续目标，不能据此认为接口和页面已实现。API 未就绪时，先完成已有链路或独立组件的可验证改进；测试夹具必须明确标注、可移除，正式入口保持待开发，不使用模拟成功冒充联调完成。

推荐顺序：D-01.1 可立即改进现有链路；D-01.2 跟随 A 的资料改密接口；D-01.3 等注册准入确定；D-02 跟随需求和收藏 API；D-03 跟随交换状态与事务实现；D-04 分别接入治理能力并完成目标平台验收。
