# C：管理端与公共设计提示词

依据 [四人任务计划](../team-work-plan.md) 的 C-01～C-04 编写，另附 B-05 的管理端协作切片。这里是待开发任务的执行提示词，不代表功能已实现，也不替代根 [AGENTS.md](../../AGENTS.md)。

在仓库根目录开启 Codex 任务，每次完整复制一个 `text` 块即可，不需要拼接公共前缀。先做 C-01 的已具备 API 切片，C-02 随新增页面完成；C-03、C-04 依赖对应后端。每次以最新源码和已合入契约核对基础与依赖。

当前已有管理布局、物品只读列表/详情、基础统计、推荐查看和公共控件展示。分类写操作、审核、账号管理、正式交换、举报争议和履历核验都需要核对 A/B 的接口进度。测试夹具只能用于组件演示；只有真实接口写入、回读及权限验证通过，才能报告业务完成。
