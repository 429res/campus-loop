# H5 与微信控件规范

设计 token 来自根目录 `shared/design-tokens.css`；材质、状态和动效来自 `src/styles/`。正文、商品图片和长表单使用稳定底色，玻璃仅用于导航与小面积控件。这是 Web / 小程序材质近似，不是 Apple 原生光学折射。

开发入口：我的 → 控件实验室，或 H5 `/#/pages/controls/controls`。

| 控件 | 公共实现 / 平台边界 |
| --- | --- |
| 导航、Tab | H5 `LoopLayout` 的可键盘导航与移动选中块；微信保留原生 navigationBar / TabBar |
| 分段选择 | `LoopSegment`，连续位移，可反向打断，选中状态可访问 |
| 按钮、图标、加载、禁用 | `LoopButton`；H5 明确 role/tabindex，native KeyboardEvent 支持 Enter/Space |
| 输入、搜索、长文本、错误 | 公共输入材质、焦点环、错误边框及独立错误文案 |
| 选择、日期 | `LoopPicker`：H5 使用浏览器原生 select/date，微信使用原生 picker；不重绘系统日历 |
| 开关、滑块 | `LoopSwitch` / `LoopSlider`，原生色值由公共组件镜像共享 token；H5 补充键盘与可访问语义，微信原生交互 |
| 分页 | 共用按钮；边界禁用、页码可见 |
| 上传 | 原生文件/相册选择，共用选择/移除按钮；上传可取消、失败可重试，期间阻止重复提交；移除只同步表单引用，不声称删除服务端文件；PNG/JPEG/GIF 最大 5 MB |
| 操作菜单、通知 | UniApp 原生 actionSheet / toast，H5 单层外壳统一材质，微信保留系统能力 |
| 弹窗 | `showAppModal` 单入口；H5 根弹层高于抽屉，捕获顶层键盘、独立滚动锁、关闭恢复；微信原生 |
| 抽屉 | `LoopSheet`，持续存在的过渡外壳、引用计数滚动锁、关闭后 inert 与 pointer-events:none；上方无确认框时才接管 Escape / Tab 与焦点返回 |

H5 开关/按钮的 UniApp 通用事件会丢失键盘字段，因此 `useKeyboard` 绑定原生 KeyboardEvent，而非假设有 tabindex 就已可键盘操作。`LoopPicker` 使用真正的浏览器 select/date 避免触摸滚轮阻碍键盘操作。

系统 `prefers-reduced-motion` 与控件页“减少动态效果”开关使用同一 Sass 降级逻辑。H5 低并发硬件自动 `data-glass=reduced`，滤镜不支持、减少透明度/高对比时使用实色。微信全部采用实色默认值。浅深色均保留可读正文与清晰焦点。

控件实验室的失败、加载、图片选择和简化材质均为明确的本地演示；失败演示不请求 API，图片只生成本地预览。简化材质开关仅在 H5 显示，微信构建继续使用原生实色组件，不模拟 Web 模糊。

新增页面优先复用公共组件。当前没有侧栏的用户端不额外制造侧栏；管理端侧栏、表格等覆盖见根设计系统文档。微信构建产物通过 `npm run test:mp-readiness` 检查原生选择器、弹窗、相册/上传、导航主题、实色材质和减少动态效果接线；该检查不替代开发者工具与真机行为验证，实际缺口见 [D-04 微信平台记录](../../docs/d04-wechat-platform-verification.md)。

本人资料与修改密码复用公共输入和按钮。只读用户名使用原生禁用态；保存、改密有独立 loading/disabled/error 状态。密码仅存在当前页面内存，收起表单、响应完成或离开登录态时清空；确认弹窗沿用 `showAppModal` 的 H5 焦点圈定与微信原生弹窗。资料写请求未收到响应时禁用再次保存，须先从服务端重新查询；改密结果不确定时清除本地会话并转到登录页确认。

独立需求页复用分段筛选、原生分类选择、输入、按钮和确认弹窗。需求与候选物品分页分别展示边界禁用；候选按钮提供选中态与 `aria-pressed`，跨页选择保留在当前内存表单。停用和逻辑删除使用不同文案与操作，删除须再次确认。`version` 冲突时当前输入保持可读并与服务器版本核对，结果不确定时锁定写入且只允许重新查询，不自动重放。

独立推荐页复用分段筛选、按钮、标签和稳定内容面板。参与者、流向、命中需求、分类硬条件与标签排序分层展示；刷新按钮有禁用态，请求可中断且旧响应不能覆盖新结果。422 使用错误面板而不是空态。收藏按钮复用 `LoopButton`，逐物品禁用防止连点；收藏夹分页区分公开卡片与不可见占位，写响应不确定时只回读、不自动重放。

D-03 发起前预览复用 `LoopSheet`，仅展示独立推荐真实返回的参与者、物品方向与命中需求；快速开关、Escape、Tab 圈定和焦点返回沿用公共抽屉。正式发起已接通服务端创建：核对抽屉后使用公共确认弹窗，占用与状态仅采用服务端结果。每个账号在本机保留待核对请求及同一发起编号；未知结果在刷新、切页、重新登录后继续核对原方案，不能改选其他方案后暗中重发原方案。

D-04 履历页复用稳定内容面板、`LoopSheet`、`LoopPicker`、`LoopSwitch` 与 `LoopButton`。H5/微信的日期、时间继续使用原生选择器；私有证据沿用原生相册/相机选择，支持逐项取消、失败重试和移除表单引用。长自述不置于多层玻璃中；分页边界、来源标签、确认进度、禁用和结果不确定恢复均有独立状态。“我的交换”抽屉只在服务端 `allowedActions` 返回 `DISPUTE` 时开放争议原因表单。通用举报因 API 未实现保持禁用，不采集输入、不产生本地编号。

C-02 本阶段只修改 `LoopSheet` 与两端公共样式/展示入口；没有改动 D-02/D-03 的业务状态、请求或待开发判断。D 对公共行为的消费复核在 Issue #29 跟踪。

发布页的非敏感草稿按已验证用户隔离保存在本机。登录过期后不自动重放上传或发布；重新登录恢复草稿时，已有上传引用仍由发布接口重新校验归属。列表与详情的加载、空态、错误重试和分页边界复用稳定内容表面，不增加新的玻璃层。

## A-02 物品审核增量

管理端增加状态选择、真实审核理由与1000字校验、提交锁定、409保留输入和显式回读、分页审计及快照展开；使用原有 Element Plus / SysDialog、共享焦点/减少动态效果样式。用户端本人审核进度使用 LoopPicker、LoopButton 与既有材质层，覆盖加载、空结果、错误重试、分页禁用及当前会话切换后丢弃旧响应。浏览器和平台验证范围见 [审核交付说明](../../docs/a02-item-review.md)，不将构建视为微信真机验收。

## D-03 正式交换操作

“我的交换”使用 LoopPicker 状态筛选、公共分页按钮和稳定详情面板；流向始终来自交换记录，物品标题按现有公开详情补充，标题读取失败只回退物品编号。倒计时仅为本机估算，不改变交换状态或操作资格。

确认参加、取消、分别声明交出/收到、登记争议复用 LoopSheet、公共文本输入、LoopButton 与 showAppModal。取消/争议原因必填；交接须明确选中实物声明并再次确认。键盘、焦点圈定、关闭恢复、加载禁用、失败提示和减少动态效果沿用公共控件。表单提供未提交草稿的取消入口，刷新详情保留当前说明和原版本；已发出但结果未知的请求不能直接清除。409 读取最新状态后由用户显式采用新版本，原说明保留，不自动补交。

本机日志只保存待核对的请求，不保存登录凭据，也不作为服务器交换记录。账号切换、页面隐藏/卸载后失效旧读取与写回；未知写请求继续按账号保留，服务端返回成功前没有成功通知。微信保留原生分页/确认能力适配，最终设备行为需开发者工具及真机验收。

D-03 嵌套确认回归：H5 实测 UniApp 默认 modal 根层为 999、抽屉为 2000，确认框按钮原先被抽屉截获。公共材质将 modal 根层提升至 3000；确认框持有独立滚动锁，抽屉暂停键盘圈定，Tab/Shift+Tab 只在顶层移动，Escape 只取消顶层（无取消按钮时不会误确认）。关闭确认框后恢复抽屉焦点，保留抽屉滚动锁；再关闭抽屉才释放最后的锁。仅 H5 使用 DOM 和样式修复，微信继续原生确认。
